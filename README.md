# Usinagem Alecrim — Site institucional

Site institucional responsivo da Usinagem Alecrim, desenvolvido com HTML, CSS e JavaScript puro.

## Estrutura do repositório

Todos os arquivos principais ficam na raiz para facilitar a publicação pelo GitHub Pages:

- `index.html` — estrutura e conteúdo do site.
- `style.css` — identidade visual, estilos e responsividade.
- `script.js` — menu mobile e ano automático do rodapé.
- `favicon.svg` — ícone da aba do navegador.

## Como visualizar

Abra `index.html` no navegador. Para desenvolvimento local, também pode usar a extensão Live Server do Visual Studio Code.

## Como publicar no GitHub Pages

1. Crie um repositório público novo, por exemplo `usinagem-alecrim-site`.
2. Envie **o conteúdo desta pasta**, e não a pasta externa, para a raiz do repositório.
3. Confirme que `index.html`, `style.css`, `script.js` e `favicon.svg` aparecem lado a lado na raiz.
4. Abra **Settings → Pages**.
5. Em **Build and deployment**, selecione `Deploy from a branch`.
6. Escolha a branch `main` e a pasta `/(root)`.
7. Clique em **Save** e aguarde o workflow do Pages terminar.
